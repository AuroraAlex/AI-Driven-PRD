# 详细设计文档模板

## 建议章节

1. 背景与目标
2. 模块范围
3. 用户场景
4. 核心流程
5. 接口设计
6. 数据模型
7. 状态与异常处理
8. 性能与扩展性考虑
9. 风险与待确认项

## 编写提示

- 先写模块边界，再写流程，不要一开始陷入接口细节。
- 对外接口要同时描述成功路径和失败路径。
- 涉及异步任务、SSE、后台索引时，要写清状态变化和重试策略。
- 涉及前后端联动时，要写清入口页面、调用接口、回显方式和错误提示。

## 最小落地要求

- 至少说明模块目标。
- 至少给出 1 条主流程。
- 至少列出当前实现入口文件。
- 至少列出 3 个边界或异常场景。
